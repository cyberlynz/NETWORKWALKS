# 🔐 Cybersecurity Lab Environment Setup

**Building an isolated virtual lab for penetration testing and ethical hacking practice**

---

## 📌 Project Overview

This project documents the setup of a controlled virtual cybersecurity laboratory using VirtualBox and Kali Linux.

The lab provides an isolated environment for authorized security testing, network reconnaissance, vulnerability assessment, packet analysis, web security testing, and other cybersecurity exercises.

---

## 🎯 Objectives

- Install and configure VirtualBox.
- Install and configure Kali Linux as a virtual machine.
- Create a private virtual network for the lab.
- Configure network connectivity for Kali Linux.
- Verify IP addressing, gateway connectivity, Internet access, and DNS resolution.
- Create a clean VM snapshot for recovery.
- Document the setup process and lessons learned.

---

## 🛡️ Security & Ethical Use

This laboratory is intended strictly for education and authorized security testing. All testing should be performed only against systems owned by the tester or where explicit permission has been granted.

---

## 🧰 Tools Used

- VirtualBox
- Kali Linux
- 7-Zip
- NetworkManager / `nmcli`
- Nmap
